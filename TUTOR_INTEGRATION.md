# ИИ-тьютор на странице лекции

Панель подключена на страницах `/lessons/:id` и `/items/:id` для типа `LECTURE`. Вопросы идут через Django по `/api/v1/tutor/chat/`. Настройка AI-сервиса и его ключа описана в `TUTOR_INTEGRATION.md` репозитория backend.

Панель показывает потоковый ответ и фрагменты материала, поддерживает отмену ответа, копирование и очистку диалога. История хранится в sessionStorage отдельно для пользователя и лекции. При смене лекции активный запрос отменяется, а на новой странице открывается её собственный диалог. На узких экранах тьютор открывается кнопкой в верхней панели.

Для локального Vite задайте `API_PROXY_TARGET=http://127.0.0.1:8010` и добавьте origin frontend в `CSRF_TRUSTED_ORIGINS` Django. Для собранного frontend также можно задать `API_PROXY_TARGET` при запуске `node server.mjs`; сервер поддерживает потоковый proxy. Без этой настройки production сохраняет схему с внешним reverse proxy.

```bash
npm ci
npm run build
npm test
API_PROXY_TARGET=http://127.0.0.1:8010 PORT=5173 node server.mjs
```

Используйте Node.js 24, как в Dockerfile. Ключ OpenAI и сервисный ключ AI не нужны frontend и не должны попадать в его bundle.

## Голос

Кнопка микрофона записывает вопрос до 60 секунд; повторное нажатие завершает запись. Распознанный текст появляется в поле вопроса, чтобы студент мог проверить его перед отправкой. Переключатель с динамиком включает автоматическую озвучку; рядом с ответами доступно ручное воспроизведение и остановка. Озвучка сейчас только на русском, распознавание также принимает казахский и английский.

При смене лекции прекращаются запись, воспроизведение и незавершённые запросы. Микрофон работает на localhost или HTTPS и требует разрешения пользователя. Это не непрерывный голосовой режим и не 3D-аватар: здесь запись отдельного вопроса, потоковый текстовый ответ и его озвучка.
