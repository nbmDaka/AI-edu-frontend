# Адресные рекомендации

В редакторах лекции и практики блок «Компетенции для рекомендаций» сохраняет `LearningItem.competency_keys` через PATCH существующего API items. Ключи совпадают с компетенциями вопросов теста, регистр и краевые пробелы не учитываются. Связи сохраняются отдельно от содержимого; черновик участвует в подборе только после публикации.

`AdaptiveResultCard` показывает `adaptive_result.recommendations` в новом результате и раскрываемой истории. Снимок причины, показателя и названия исторический; ссылка строится исключительно из вычисленного сервером `available_item_short_id`. Закрытый материал остаётся текстом с пометкой недоступности. Старые попытки и неполные связи возвращают к общему повторению модуля. Обязательное повторение всех материалов после неуспеха сохраняется.

Ориентир рекомендаций версии 1 — показатель компетенции строго ниже 50%; это наше правило помощи, оно не меняет формулу, модульный порог или допуск. Порядок: показатель/ключ компетенции, затем учебный порядок материалов. Поддерживаются ru/en/kz и мобильный экран.

Перед обновлением frontend нужен backend с миграцией education `0020_learningitem_competency_keys`. Полная схема снимка и настройка описаны в backend `docs/adaptive-recommendations.md`. Проверки: `src/Recommendations.test.tsx`, общий Vitest/build и реальный локальный Playwright `e2e/adaptive.integration.e2e.ts` на временной SQLite, без API-заглушек.
